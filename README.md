# LP Tools

Scripts and plugins for 3D, animation and VFX, with documentation and guides for every tool.

**Website: [lptools.store](https://lptools.store)**

This repository is the source of the LP Tools website: the tool pages, the documentation and the guides. The tools themselves are sold on [Gumroad](https://lptools.gumroad.com).

## Tools for Autodesk Maya

- [Modifier Stack](https://lptools.store/tools/modifier-stack/): a 3ds Max style modify panel for Maya.
- [KeyForge](https://lptools.store/tools/keyforge/) and [KeyForge Lite](https://lptools.store/tools/keyforge-lite/): a tween machine and animation toolkit.
- [Roll Anything](https://lptools.store/tools/roll-anything/): roll any shape across the ground with no slipping.
- [GLB Bridge](https://lptools.store/tools/glb-bridge/): import and export glTF and GLB.
- [Camera Toolkit](https://lptools.store/tools/camera-toolkit/): everyday camera helpers in one window.
- [Material Generator](https://lptools.store/tools/material-generator/): build materials from a texture folder for Arnold, Redshift or V-Ray.
- [fSpy Importer for Maya and 3ds Max](https://lptools.store/tools/fspy-importer-maya/): photo camera match.
- [Mixamo Auto Control Rig](https://lptools.store/tools/mixamo-auto-control-rig/): a Python 3 update of the old script, free.
