# Terms and License

Last updated October 15, 2026

Every LP Tools download includes a `LICENSE.txt` file. That file is the official license and it is what applies to the tool you have. This page is a plain-language summary.

## What you can do

- Use the tool for personal and commercial work, including client projects.
- Keep everything you make with it (scenes, renders, animation, assets). It is yours.
- Install it on any computers you personally use.
- Change the code for your own use.

## What you can't do

- Share, sell, rent, sublicense or give away the tool, or a changed version of it.
- Include it in another product, tool, asset pack, template or course download.
- Remove the license or the copyright notice from the files.

Need one of these? Ask for written permission at [{{ site.support_email_display }}](mailto:{{ site.support_email }}).

## Who the license covers

- **Single-artist license:** one license is for one person.
- **Studio license:** where offered and named on your receipt, it covers up to the stated number of artists at one company or team.
- Otherwise a studio or team needs one license for each artist who uses the tool. For more artists, buy more licenses or ask for a quote.

## Updates

Updates you receive are covered by the same license.
